## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/tanishks-07/Web-Development-project.git
```

Go into a project folder:

```bash
cd Web-Development-project
cd "Application form"
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
